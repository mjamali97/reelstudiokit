# راهنمای Reel Studio · قدم‌به‌قدم

> کیت: github.com/mjamali97/reelstudiokit · لایسنس MIT

این پوشه یه «استودیوی محتوا»ست که توی Claude Code کار می‌کنه: از ایده تا اسکریپت، ادیت موشن، چک کیفیت، و انتشار توی
اینستاگرام، یوتیوب و کانال تلگرام. برای هر نوع پیجی ساخته شده: پیج شخصی، متخصص، شیرینی‌فروشی، کافه، کلینیک، فروشگاه
آنلاین، دوره‌ی آموزشی.

هیچ اطلاعات شخصی‌ای توش نیست. هر جا مثال دیدی (مثلاً قالب پست یا کپشن)، فقط «مثال»ه؛ موقع ستاپ، Claude با خودت
قالب خودت رو می‌سازه.

## قبل از شروع: چی لازم داری

**حساب‌ها**
- **Claude** با دسترسی Claude Code (پلن Pro یا بالاتر).
- **اینستاگرام حرفه‌ای** (Creator یا Business): Settings → Account type.
- **Zernio** (zernio.com): انتشار و زمان‌بندی اینستاگرام و یوتیوب، دایرکت خودکار برای کامنت، آمار. وقتی این رو
  نوشتیم (مهر ۱۴۰۵ / اکتبر ۲۰۲۶) دو تا حساب اول رایگان بود و بعدش ماهی حدود ۶ دلار برای هر حساب؛ قیمت امروز رو خودت
  توی zernio.com/pricing ببین.
- **تلگرام** (برای کانال و دو تا بات).
- **Google AI Studio** (کلید رایگان Gemini، برای سرچ و نوشتن پیش‌نویس توی بات).
- **Cloudflare** (رایگان؛ بات‌ها اینجا اجرا می‌شن، بدون سرور و بدون اینکه لپ‌تاپت روشن باشه).
- **GitHub** (رایگان؛ یه ریپوی خصوصی برای همین پوشه).

**روی کامپیوترت**
- مک (یا ویندوز با WSL2، یا لینوکس)، Google Chrome، و این‌ها:
  `git`، `node` (نسخه‌ی ۲۰ به بالا)، `python3` (۳.۱۱ به بالا)، `ffmpeg`، `uv`.
- روی مک: اول Homebrew رو از brew.sh نصب کن، بعد توی ترمینال:
  ```bash
  brew install git node python ffmpeg uv
  ```

**هزینه:** به‌جز اشتراک Claude و حساب‌های پولی Zernio (اگه از سقف رایگانش رد بشی)، بقیه رایگانه.

## قدم ۱ · نصب Claude Code و باز کردن پوشه

1. Claude Code رو نصب کن (راهنما: docs.claude.com → Claude Code). یا اپ دسکتاپ Claude رو نصب کن، یا افزونه‌ی VS Code.
2. کیت رو از گیت‌هاب بگیر (یه جای ثابت، مثلاً پوشه‌ی Documents):
   ```bash
   git clone https://github.com/mjamali97/reelstudiokit.git my-studio
   cd my-studio
   claude
   ```
   اگه با git راحت نیستی: توی صفحه‌ی گیت‌هاب کیت، Code ← Download ZIP، بازش کن، ترمینال رو توی همون پوشه باز کن و
   بنویس `claude`.
4. اولین پیام: `/setup`

از اینجا به بعد Claude قدم‌به‌قدم می‌پرسه و انجام می‌ده. پایین توضیح دادیم هر قدم چیه که بدونی چه خبره.

## قدم ۲ · معرفی خودت (پروفایل)

Claude سه دور سؤال کوتاه می‌پرسه:
- **چه جور پیجی هستی؟** شخصی، متخصص، یا کسب‌وکار (چی می‌فروشی، قیمت‌ها، محدوده‌ی ارسال، ساعت کاری، مردم چطوری
  سفارش می‌دن، چی بیشتر ازت می‌پرسن).
- **مخاطبت کیه؟** کجاست، چی جلوش رو گرفته (پول، دسترسی، اعتماد، وقت).
- **چطوری کار می‌کنی؟** هفته‌ای چند تا ریل، کدوم روزها فیلم می‌گیری، هدف سه ماه آینده‌ت.

جواب‌ها توی `profile/CREATOR.md` ذخیره می‌شن. هیچ عددی رو حدس نمی‌زنه؛ اگه چیزی رو نمی‌دونی، بگو «نمی‌دونم».

### راهنمای مخصوص کسب‌وکار تو

برای ۲۰ نوع کسب‌وکار یه راهنمای محتوا توی `playbook/business/` هست (فهرستش توی `INDEX.md`):

| | | | |
|---|---|---|---|
| رستوران و کافه | شیرینی‌فروشی | آتلیه‌ی عکاسی | فروشگاه آنلاین |
| سالن زیبایی | کلینیک و پزشک | متخصص و خدمات (مشاور، وکیل، دوره) | پیج شخصی |
| باشگاه و مربی | مشاور املاک | خدمات خودرو | آموزشگاه زبان و کنکور |
| خیاطی و طراح لباس | دکوراسیون و مبلمان | گل‌فروشی | طلا و جواهر |
| آژانس مسافرتی و تور | هتل و بوم‌گردی | صنایع دستی و هندمید | عروسی و تشریفات |
 هر کدوم می‌گه
مشتری‌ت کیه، چه ریل‌هایی جواب می‌ده (با قلاب نمونه)، هر هفته چه شات‌هایی بگیری، با کامنت چی بهشون بدی، و چه
کارهایی رو نباید بکنی. اگه کسب‌وکارت توی لیست نیست، Claude موقع ستاپ با خودت یکی مخصوص خودت می‌نویسه.

## قدم ۳ · لحن خودت

دو سه تا از ویدیوهای قبلیت (یا زیرنویس‌شون، یا یه ویس ۶۰ ثانیه‌ای که توش می‌گی چی کار می‌کنی) رو بهش بده.
Claude از روی حرف زدن واقعی خودت می‌نویسه که جمله‌هات چطوریه، چطوری شروع و تموم می‌کنی و چطوری می‌گی «کامنت کن».
از این به بعد هر اسکریپتی با این فایل (`profile/VOICE.md`) چک می‌شه، که شبیه شعار و متن نوشتاری نشه و شبیه خودت باشه.

## قدم ۴ · دیزاین سیستم (رنگ، فونت، لوگو)

- اگه داری: فایل‌ها و کدهای رنگت رو بده.
- اگه نداری: Claude می‌پرسه سه تا کلمه برای حس پیجت چیه و از کدوم پیج‌ها خوشت میاد، بعد سه تا پیشنهاد می‌سازه
  (پالت رنگ + فونت فارسی + نمونه‌ی کاور و استوری) و تو انتخاب می‌کنی یا ترکیب می‌کنی.
- فونت فقط با مجوزی که اجازه‌ی استفاده توی ویدیو و وب بده (مثل وزیرمتن که پیش‌فرض همین کیته).
- لوگوی کانال تلگرام و عکس دو تا بات هم همین‌جا ساخته می‌شه.

## قدم ۵ · قالب‌های خودت

این مهم‌ترین قدمه، چون هر چیزی که به اسم تو نوشته می‌شه از این قالب‌ها پیروی می‌کنه. Claude مثال کیت رو نشونت
می‌ده و با هم قالب خودت رو می‌سازید:

| قالب | مثال کیت | مثال یه شیرینی‌فروشی |
|---|---|---|
| کپشن اینستاگرام | سؤال قلاب ← «کامنت کن X» ← توضیح و لینک ← سیو و شیر ← ۵ هشتگ | اسم محصول و یه خط حسی ← قیمت و نحوه‌ی سفارش ← «کامنت کن «منو»» ← آدرس و ساعت ← هشتگ شهر و محصول |
| پست کانال تلگرام | ایموجی و معرفی، لینک‌ها، 🔴 نکته، #کلمه، امضا | عکس امروز، اسم و قیمت، لینک سفارش، «تا سه روز توی یخچال می‌مونه» |
| استوری | ۲–۳ فریم کوتاه، فلش برای بعدی، استیکر لینک یا نظرسنجی | پخت امروز + نظرسنجی «کدوم رو فردا بپزیم؟» |
| دایرکت خودکار | پیام ۱: توضیح و لینک؛ پیام ۲: خود فایل/پرامپت | منو با قیمت، یا لینک سفارش |
| جواب زیر کامنت | ۱۲ جمله‌ی کوتاه که می‌چرخن («فرستادم، دایرکتت رو چک کن 🙌») | به لحن خودت |
| خلاصه‌ی خبر | خبرهای حوزه‌ی کارت هر سه روز (پیش‌فرض خاموش) | معمولاً خاموش |

قالب‌ها توی `playbook/` و فایل `telegram-bot/src/formats.js` ذخیره می‌شن تا هم Claude و هم بات دقیقاً همین‌طوری بنویسن.

## قدم ۶ · Zernio (انتشار اینستاگرام و یوتیوب)

1. توی zernio.com ثبت‌نام کن.
2. از داشبورد Zernio، اینستاگرام (و اگه خواستی یوتیوب) رو وصل کن.
3. Zernio → API Keys → یه کلید بساز.
4. توی پوشه، فایل `.env.example` رو کپی کن به اسم `.env` و کلید رو **خودت** جلوی `ZERNIO_API_KEY=` بذار.
   کلید رو هیچ‌وقت توی چت نفرست.
5. Claude با این دستور چک می‌کنه وصله (کلید رو نشون نمی‌ده):
   ```bash
   python3 -I tools/zernio/zernio.py accounts
   ```

## قدم ۷ · تلگرام: کانال و دو تا بات

1. **کانال:** New Channel ← عمومی، با یه آیدی (مثلاً `t.me/mybakery`). توضیحات کوتاه (زیر ۲۵۵ کاراکتر) و یه پست سنجاق‌شده
   که بگه اینجا چی پیدا می‌شه. Claude متن‌ها رو با قالب خودت پیشنهاد می‌ده.
2. **دو تا بات** با @BotFather و دستور `/newbot`:
   - **بات استودیو:** صندوق ایده‌ها و تأییدها، فقط خودت بهش دسترسی داری.
   - **بات ناشر:** پست‌ها رو بعد از تأیید نهایی تو، توی کانال می‌ذاره.
   هر کدوم یه توکن می‌ده. توکن‌ها رو **فقط** توی GitHub Secrets می‌ذاری (قدم ۸)، نه توی چت.
3. بات ناشر رو توی کانال **ادمین** کن، با دسترسی «Post messages».
4. آیدی عددی خودت: به @userinfobot پیام بده و عدد رو به Claude بگو (این عدد رمز نیست).
5. کلید Gemini: aistudio.google.com ← Get API key (رایگان).

## قدم ۸ · Cloudflare و GitHub (روشن کردن بات‌ها)

1. **Cloudflare:** ثبت‌نام رایگان. Account ID رو از صفحه‌ی Workers & Pages بردار.
   یه API Token بساز: My Profile ← API Tokens ← Create Token ← قالب «Edit Cloudflare Workers»، بعد این دو تا دسترسی
   رو هم اضافه کن: `D1 · Edit` و `Browser Rendering · Edit`.
2. **GitHub:** یه ریپوی **خصوصی** برای خودت بساز. Claude کمکت می‌کنه push کنی و کیت اصلی رو هم به‌عنوان «upstream» وصل
   نگه می‌داره که بعداً `/update` کار کنه. فایل `.env` و ویدیوها هیچ‌وقت آپلود نمی‌شن.
3. Claude تنظیمات بات رو با تو پر می‌کنه (`telegram-bot/wrangler.jsonc`): اسم برند، آیدی‌ها، مخاطب، منطقه‌ی زمانی،
   روزها و ساعت انتشار، رنگ استوری‌ها.
4. **Secrets:** توی GitHub ← Settings ← Secrets and variables ← Actions، خودت این‌ها رو اضافه می‌کنی:
   `CLOUDFLARE_API_TOKEN`، `CLOUDFLARE_ACCOUNT_ID`، `STUDIO_BOT_TOKEN`، `PUBLISHER_BOT_TOKEN`، `ZERNIO_API_KEY`،
   `GEMINI_API_KEY`، و سه تا رمز تصادفی که Claude برات می‌سازه: `WEBHOOK_SECRET`، `SETUP_KEY`، `INGEST_KEY`.
   توی تب Variables هم `BOT_URL` (آدرس بات روی workers.dev).
5. Claude اول تست‌های بات رو اجرا می‌کنه (`bash telegram-bot/test/all.sh` باید ALL GREEN بده)، بعد push می‌کنه و
   GitHub خودش بات‌ها رو روی Cloudflare روشن می‌کنه.

## قدم ۹ · تست، بعد زنده

بات‌ها اول توی **حالت تست** هستن: هر پستی که تأیید کنی فقط برای خودت میاد (با برچسب «تست») و Zernio هیچی نمی‌فرسته.
1. توی بات استودیو `/start` بزن: منوی ۹ دکمه‌ای میاد.
2. یه لینک بفرست: کارت ایده میاد.
3. 🔎 سرچ رو امتحان کن.
4. از کارت ایده «✍️ پست تلگرام بساز» ← ✅ ← توی بات ناشر ✅ ← پست فقط برای خودت میاد.

هر وقت همه‌چیز درست بود به Claude بگو «زنده‌ش کن». اون موقع پست‌ها می‌رن کانال و Zernio واقعاً زمان‌بندی می‌کنه
(باز هم فقط بعد از ✅ خودت).

## کار روزانه بعد از ستاپ

1. **ایده:** هر لینک یا فکری رو برای بات استودیو بفرست. دکمه‌ی 🧠 امتیاز وایرال می‌ده.
2. **برنامه‌ی هفته:** `/content-plan` ریل‌ها، استوری‌ها و پست‌های هفته رو از روی راهنمای کسب‌وکارت می‌چینه و لیست
   شات‌هایی که باید فیلم بگیری رو می‌ده (مرتب‌شده بر اساس مکان، که یه‌جا همه رو بگیری).
3. **اسکریپت:** توی Claude Code بنویس `/reel-idea` و ایده رو بگو. اول درستی‌ش رو چک می‌کنه، بعد سه تا قلاب، اسکریپت به
   لحن خودت، امتیاز از ۱۰ (و ضعیف‌ترین بخشش)، و دو سه تا سبک ادیت پیشنهاد می‌ده.
4. **فیلم:** عمودی، با صدای تمیز، به حرف خودت (اسکریپت راهنماست، نه متن حفظی). زیرنویس (SRT) رو هم خروجی بگیر.
5. **سبک:** `/reel-style` یا مستقیم یکی از این‌ها: `/vogue` (مجله‌ای) · `/hud` (حس دیجیتال و صفحه‌نمایش) · `/swiss`
   (تایپوگرافی درشت و تند) · `/vox` (مستند و کلاژ) · `/doodle` (نقاشی دستی).
6. **چک کیفیت:** قبل از اینکه چیزی ببینی، Claude ویدیو رو با یه چک‌لیست کامل چک می‌کنه (سیف‌زون اینستاگرام، فریم خالی،
   یخ‌زدگی، اندازه‌ی متن، صدا).
7. **تأیید و انتشار:** وقتی گفتی اوکیه، `/publish` ویدیو رو به‌صورت پیش‌نویس توی Zernio می‌ذاره و یه کارت توی بات
   استودیو برات می‌فرسته. با یه ✅ روی کارت: اینستاگرام و یوتیوب زمان‌بندی می‌شن، دایرکت خودکار برای کلمه‌ی کامنت
   روشن می‌شه، و پست تلگرام برای تأیید نهایی می‌ره توی بات ناشر.
8. **آمار:** یه روز و یه هفته بعد، `/analytics`. می‌گه چی گرفت و چرا، و قلاب‌ها و امتیازها رو از روی آمار خودت به‌روز می‌کنه.

خودکار هم هست: هر روز صبح یه پیشنهاد استوری و (اگه روشنش کنی) هر سه روز یه خلاصه‌ی خبر توی بات استودیو میاد؛
هیچ‌کدوم بدون ✅ تو منتشر نمی‌شن.

## گزارش‌های خودکار و داشبورد (توی تلگرام)

بعد از ستاپ، بات استودیو خودش این‌ها رو برات می‌فرسته (فقط برای خودت):
- **هر روز ساعت ۹ صبح:**
  - فالوورهایی که دیروز اومدن و رفتن.
  - روند ۷ روز اخیر در برابر هفته‌ی قبلش، با یه نمودار کوچیک.
  - بازدید ۳۰ روز.
  - **امتیاز پیج از ۱۰۰**، که از پنج بخش ساخته می‌شه: رشد فالوور، بازدید ریل‌ها، سیو و شیر، نگه داشتن بیننده، نظم انتشار. هر بخش با میانگین خود پیجت مقایسه می‌شه، نه با یه عدد من‌درآوردی.
  - بهترین پست هفته.
- **۲۴ ساعت بعد از هر ریل:**
  - بازدید و رتبه‌ش بین ریل‌های قبلیت.
  - سیو و شیر در هر هزار بازدید در برابر میانگین.
  - اینکه چند درصد رد کردن و تا کجا دیدن.
  - فالوورهای همون روز.
  - چند نفر کلمه‌ی گیت رو کامنت کردن و دایرکت گرفتن.
  - قوی‌ترین و ضعیف‌ترین بخشش، با یه پیشنهاد.
- **۷ روز بعد از هر ریل:** یه گزارش کوتاه که بعد از اون ۲۴ ساعت چقدر ادامه داد.
- **هشدار:** اگه اینستاگرامت از Zernio قطع بشه، فوری خبرت می‌کنه.
- **دکمه‌ی 📊 داشبورد:** یه صفحه‌ی خصوصی که هر بار بازش کنی از Zernio تازه می‌شه. توش این‌هاست:
  - نمودار فالوور و نمودار امتیاز در طول زمان.
  - قوت و ضعف پیج.
  - شهر و سن فالوورها.
  - بهترین ساعت‌های پست.
  - جدول همه‌ی پست‌ها، که با زدن روی هر ستون مرتب می‌شه.

ساعت گزارش رو هر وقت خواستی عوض کن (`DAILY_REPORT_AT`)، یا خاموشش کن.

## آنالیز پیج (`/page-audit`)

آخر ستاپ یه بار، و بعدش ماهی یه بار، بنویس `/page-audit` (یا بگو «پیجم رو آنالیز کن»). Claude این‌ها رو بررسی می‌کنه:
- **پروفایل:** اسم، بیو، لینک، هایلایت‌ها و عکس پروفایل. از اسکرین‌شات‌هایی که خودت می‌فرستی، یا فقط با نگاه کردن توی کروم خودت.
- **گرید:** کاورها و پست‌های پین‌شده.
- **محتوا:** ترکیب محتوا، قلاب‌ها، اینکه مردم تا کجای ویدیو رو می‌بینن، سیو و شیر.
- **مخاطب:** شهر، سن و جنسیت فالوورها (از Zernio)، و اینکه با مشتری واقعی‌ت جور هست یا نه.
- **زمان‌بندی:** روزها و ساعت‌های پست، و اینکه چقدر منظم پست می‌ذاری.
- **فروش:** مسیر تبدیل بیننده به مشتری (دایرکت، سفارش، رزرو).
- **رقبا:** ۳ تا ۵ پیج رقیب یا الگو که خودت اسم می‌بری.

خروجی‌ش این‌هاست:
- به هر بخش یه نمره می‌ده.
- **۵ کار اول** رو به ترتیب اثر می‌گه، مثلاً متن بیوی جدید در دو نسخه، هایلایت‌هایی که باید بسازی، پست‌هایی که باید پین کنی، روز و ساعت پست.
- یه برنامه‌ی دو هفته‌ای می‌چینه.

همه‌ش توی `profile/audits/` ذخیره می‌شه و آنالیز ماه بعد با همین مقایسه می‌شه که ببینی چی بهتر شده. فقط با عددهای
واقعی کار می‌کنه و هیچ عددی رو حدس نمی‌زنه.

## آپدیت کیت (`/update`)

کیت مرتب بهتر می‌شه: سبک جدید، کسب‌وکار جدید، امکانات جدید توی بات. هر وقت خواستی بنویس `/update`. نسخه‌ی جدید رو از
گیت‌هاب می‌گیره و هر چیزی که مال خودته دست نمی‌خوره: پروفایل، برند، قالب‌هات، تنظیمات بات و ریل‌ها. بعدش بهت
می‌گه چی اضافه شده و اگه کاری لازمه چیکار کنی، تست‌ها رو اجرا می‌کنه و بات رو دوباره روشن می‌کنه. نسخه‌ی فعلی توی
فایل `VERSION` نوشته شده.

## اگه Claude اشتباه کرد

بهش بگو. هر قانونی که بگی («همیشه…»، «هیچ‌وقت…») توی `profile/RULES.md` ذخیره می‌شه و دفعه‌ی بعد هم رعایت می‌شه.
ایده‌ای که نخواستی رو بگو تا توی `profile/IDEAS-REMOVED.md` بره و دیگه پیشنهاد نشه.

## امنیت

- هیچ‌چیزی بدون ✅ تو منتشر نمی‌شه (برای تلگرام دو بار: استودیو و ناشر).
- کلیدها فقط توی `.env` (که آپلود نمی‌شه) و GitHub Secrets. هیچ‌وقت توی چت.
- Claude به‌جای تو ثبت‌نام نمی‌کنه و رمز وارد نمی‌کنه؛ صفحه رو باز می‌کنه و تو انجام می‌دی.
- هیچ عدد، نظر مشتری یا صفحه‌ی ساختگی‌ای ساخته نمی‌شه. هر عدد از منبع واقعی میاد.

| مشکل | راه حل |
|---|---|
| بات جواب نمی‌ده | به Claude بگو `BOT_URL/setup?key=…&info=1` رو چک کنه (کلید رو خودت توی مرورگر باز کن) |
