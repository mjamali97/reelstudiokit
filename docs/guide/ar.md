# ريل ستوديو · الدليل الكامل

**اللغات:** [English](en.md) · [فارسی](fa.md) · العربية · [Türkçe](tr.md) · [Deutsch](de.md) · [Français](fr.md) · [Italiano](it.md)

ريل ستوديو استوديو محتوى يعمل داخل [Claude Code](https://claude.com/claude-code). تتحدث مع Claude بلغتك؛ فيخطط منشوراتك،
ويكتبها بصوت علامتك التجارية، ويحرّر الريلز بـ14 أسلوب موشن، ويصمّم الكاروسيل والستوري وأغلفة الهايلايت بألوان علامتك وخطوطها،
وينشر عبر Zernio بعد موافقتك ✅، ويرسل لك الأرقام كل صباح على تيليغرام. يناسب أي صفحة: مخبز، مطعم، استوديو تصوير، صالون،
عيادة، متجر إلكتروني، خبير، صفحة شخصية، أو وكالة لديها عدة عملاء.

---

## ١ · جرّبه أولاً (٥ دقائق، بلا أي حساب)

<div dir="ltr">

```bash
git clone https://github.com/mjamali97/reelstudiokit.git my-studio
cd my-studio
bash tools/install.sh
bash telegram-bot/demo/demo.sh ar
```

</div>

تفتح صفحة بثلاثة أعمدة: **بوت الاستوديو** و**بوت النشر** و**قناتك**. اضغط 📝 المسودات ← ✅ على المنشور ← ✅ النهائية في عمود
بوت النشر، وشاهده يصل إلى القناة. افتح 📊 لوحة البيانات و💬 صندوق الرسائل، وأرسل أي رابط. لا شيء يغادر جهازك. أوقفه بـ Ctrl-C.

الأمثلة المرئية في `examples/bakery/` (مخبز وهمي): ١٠ قوالب كاروسيل، ١١ قالب ستوري، أغلفة هايلايت. `fonts/gallery.html` يعرض
الخطوط الواحد والخمسين. وفي Claude Code يأخذك الأمر `/demo` في جولة على كل ذلك.

## ٢ · ما تحتاجه

| | |
|---|---|
| الجهاز | ماك، لينكس، أو ويندوز مع WSL2 |
| البرامج | git، Node 20 فأعلى، Python 3.11 فأعلى، ffmpeg، Google Chrome، uv (`bash tools/install.sh` يخبرك بما ينقص وكيف تثبّته) |
| Claude Code | اشتراك Claude أو مفتاح API |
| الحسابات (للنشر الفعلي فقط) | حساب إنستغرام احترافي، [Zernio](https://zernio.com) (النشر والأرقام)، تيليغرام، مفتاح Gemini مجاني، حساب Cloudflare مجاني، GitHub |

مستويات التثبيت: `bash tools/install.sh` (الأساس: كاروسيل، ستوري، ترجمة مدمجة، أدوات العلامة، البوتات) · `video` (محرّك الريلز،
توقيت الكلمات WhisperX، مدقق الطباعة الفارسية) · `all` (مهارات HyperFrames وإضافة محرر NextWork) · `check` (تقرير فقط). كل الأدوات
وتراخيصها: `tools/STACK.md`.

## ٣ · كيف يسير الإعداد

افتح المجلد في الطرفية، شغّل `claude` واكتب **`/setup`**. إنه محادثة لا استمارة؛ توقّف متى شئت وسيكمل من حيث توقف
(`profile/SETUP-STATUS.md`). نحو ساعة في المجمل.

| المرحلة | ماذا يحدث | ماذا تفعل |
|---|---|---|
| ٠ الترحيب | لغتك، إعداد كامل / العرض أولاً / عميل وكالة | تختار |
| ١ الاستكشاف | نوع النشاط وما هو موجود | تحدد ما لديك: موقع، إنستغرام، دليل هوية أو شعار، قائمة أسعار، خرائط غوغل؛ وتشارك الروابط والملفات |
| ٢ القراءة | يقرأ Claude موقعك (الألوان، الخطوط، الشعار، الأسعار) ولقطات إنستغرام وملفاتك، ثم يعرض **«هذا ما فهمته»** مع معاينة علامتك على إطارات حقيقية | تصحّح الأخطاء |
| ٣ الملف والصوت | فقط الأسئلة التي لم تجب عنها موادك؛ ثم **صوت العلامة**: درجة الرسمية، صيغة المخاطبة، كلمات تستخدمها وتتجنبها، واختبار العينات («أي الثلاثة يشبهك؟») | تجيب، تختار، تعدّل |
| ٤ نظام التصميم | يُستورد مظهرك الحالي، أو ثلاثة اتجاهات جنباً إلى جنب للاختيار؛ ثم يُطبَّق على كل الأدوات | تختار أو تمزج |
| ٥ أول تدقيق | صفحتك من البيانات العامة: نقاط القوة والضعف، أهم ٥ إصلاحات، بايو وأغلفة هايلايت جاهزة | تطبّق المكاسب السريعة |
| ٦ الخطة والقوالب | دليل نشاطك، قوالبك الخاصة للتعليق والكاروسيل والستوري والمنشور، خطة أول أسبوعين | تختار |
| ٧–٨ الحسابات والبوتات | Zernio، قناة وبوتان على تيليغرام، Cloudflare وGitHub، نشر في **وضع الاختبار** | تنقر، وتضع المفاتيح بنفسك في `.env` أو GitHub |
| ٩ خط الأساس | أرقامك الحقيقية، أفضل أوقات النشر، التدقيق الكامل | تقرأ |
| ١٠ الإطلاق | المنشورات تصل إلى القناة، وZernio يخرج من وضع التجربة | تقول «أطلق» |

لا تلصق أي كلمة مرور أو مفتاح في المحادثة أبداً. يفتح Claude الصفحة الصحيحة، وتكتب السر بنفسك في مكانه.

## ٤ · علامتك، وتغييرها لاحقاً

كل ما يصنعه الاستوديو يقرأ ثلاثة ملفات:
- `brand/brand.json`: الألوان والخطوط والشعار والاسم والمعرّف واللغة. الخطوط من المكتبة المفتوحة في `fonts/` أو خطك المرخّص.
- `profile/CREATOR.md`: الحقائق: ما تبيعه، الأسعار (كلٌّ بمصدره)، ساعات العمل، طريقة الطلب، العملاء، الإثباتات، الأهداف.
- `profile/VOICE.md`: الصوت: الشخصية، النبرة، صيغة المخاطبة، الكلمات، الإيموجي، الرد على العملاء، جمل مناسبة وغير مناسبة.

غيّر أياً منها بـ **`/brand`** («اجعل ألواننا أدفأ»، «نحن لا نقول رخيص أبداً»، «هذا شعارنا الجديد»). يعرض معاينة أولاً، ثم يشغّل
`node tools/brand/apply.mjs` لينقل التغيير إلى أساليب الفيديو وألوان البوت وصوته.

**صور وموسيقى وأيقونات: فقط ما يحق لك استخدامه** (`/assets`). مدمج: نحو ٧٠٠٠ أيقونة (Lucide وTabler وPhosphor وHeroicons)،

## ٦ · النشر

لا يُنشر شيء دون موافقتك ✅. يرفع `/publish` التصيير المعتمد إلى Zernio **كمسودة**، ويكتب التعليق بقالبك، ويضبط بوابة
التعليق-إلى-الرسائل، ويرسل بطاقة إلى بوت الاستوديو. موافقة واحدة تجدول إنستغرام (ويوتيوب إن كان متصلاً). منشورات قناة
تيليغرام تحتاج موافقة نهائية ثانية في بوت النشر الذي يعرض المنشور كما سيظهر تماماً.

## ٧ · بوتات تيليغرام

بوتان على Cloudflare Worker مجاني، وقائمتهما تتحدث لغتك (`LANG` في `telegram-bot/wrangler.jsonc`: ar للعربية).

| الزر | وظيفته |
|---|---|
| 🎬 الريلز · 💡 الأفكار · 📝 المسودات | خط الإنتاج؛ أي رابط أو نص ترسله يُحفظ فكرة، ثم يُبحث ويُقيَّم |
| 📅 الجدول | تقويم المحتوى: ما المجدول وما الناقص |
| 📸 الستوري · 📰 الأخبار | فكرة ستوري كل صباح بصوتك، وملخص أخبار مجالك (اختياري) |
| 🔎 البحث | إجابة عن سؤال مع المصادر |
| 📊 لوحة البيانات | صفحة خاصة: المتابعون، الوصول، تقييم الصفحة، الجمهور، أفضل الأوقات، كل المنشورات، التقويم، المنافسون |
| 💬 صندوق الرسائل | تعليقات ورسائل جديدة مع رد مقترح بصوتك ومعلوماتك: ✅ أرسل، ✏️ أكتب بنفسي، ❌ تجاهل |
| ⚙️ الحالة | ما المفعّل وما في وضع الاختبار |
| 👥 العملاء | في وضع الوكالة فقط |

**رسائل تلقائية:** تقرير يومي الساعة ٩ صباحاً (متابعو الأمس، اتجاه ٧ أيام، تقييم الصفحة من ١٠٠ بأجزائه الخمسة)، تقرير بعد ٢٤
ساعة و٧ أيام من كل منشور (المشاهدات مقارنة بمتوسطك، الحفظ، المشاركة، تعليقات البوابة، المتابعون)، تقرير أسبوعي عن المنافسين،
وتقرير PDF شهري.

## ٨ · الأرقام والتدقيق

`/analytics` يجلب أرقامك من Zernio ويحدّث ما ينجح: الافتتاحيات، تقييمات الأساليب، أيام النشر.
`/page-audit` يدقق الصفحة كلها (الملف، الشبكة، مزيج المحتوى، الاحتفاظ، تطابق الجمهور مع عميلك، التوقيت، التحويل، المنافسون):
نقاط القوة والضعف، أهم ٥ إصلاحات، خطة أسبوعين. مرة شهرياً تكفي.

## ٩ · وضع الوكالة (عدة عملاء)

استخدامه لعملائك يحتاج ترخيصاً تجارياً (`COMMERCIAL-LICENSE.md`)؛ تجربة وضع الوكالة مجانية.

<div dir="ltr">

```bash
node tools/client.mjs init my-first-client
node tools/client.mjs new cafe-dubai "Cafe Dubai"
node tools/client.mjs use cafe-dubai
```

</div>

شغّل `/setup` لكل عميل (اختر «إعداد عميل»). حساب Zernio واحد مع **ملف** لكل عميل، وزوج بوتات مع `AGENCY: "on"`: أضفهم من
👥 العملاء، ويستطيع كل عميل الانضمام برابط دعوة واستلام تقاريره، و`node tools/client.mjs sync <slug> --id <n>` يمنح مساعد الرسائل
صوت ذلك العميل ومعلوماته. التفاصيل: `playbook/AGENCY.md`.

## ١٠ · التحديث

اكتب `/update` (أو `bash tools/update.sh`). يجلب الإصدار الجديد، ويُبقي كل ما هو لك (الملف، العلامة، القوالب، الريلز، إعدادات
البوت؛ القائمة في `.gitattributes`)، ويعرض الجديد وما إذا كان تغييرٌ ما يتطلب إجراءً منك.

## ١١ · اللغات

- **المحتوى:** أي لغة يكتبها Claude؛ المصيّرات تتعامل مع الكتابة من اليمين إلى اليسار (العربية، الفارسية) ومن اليسار إلى اليمين بخطوط وأرقام مناسبة.
- **قوائم البوت:** `LANG` = `en`، `fa`، `ar`، `tr`، `de`، `fr`، `it`.
- **هذا الدليل:** بكل اللغات السبع، والروابط في أعلى الصفحة.

## ١٢ · الأمان والخصوصية

- لا يُنشر شيء دون موافقتك (مرتين لتيليغرام). الرفع يكون كمسودات.
- المفاتيح في `.env` (لا يُرفع أبداً) وفي أسرار GitHub/Cloudflare. لن يطلب منك Claude لصق مفتاح في المحادثة.
- مستودعك خاص؛ والعدّة نفسها لا تحوي أي بيانات شخصية.
- لا يظهر على الشاشة أو في التعليق إلا ما له مصدر؛ لا أسعار أو مراجعات أو أرقام مختلقة.
- اختبارات البوت تعمل على محاكيات: `bash telegram-bot/test/all.sh`.

## ١٣ · حل المشكلات

| المشكلة | الحل |
|---|---|
| `install.sh` يقول إن شيئاً ناقص | ثبّته بالأمر الذي يطبعه ثم أعد التشغيل |
| التصيير يقول إن خطاً لم يُحمَّل | معرّف الخط في `brand/brand.json` غير موجود في `fonts/fonts.json`، أو مسار `css` لخطك خاطئ |
| البوت لا يرد | افتح بنفسك `<BOT_URL>/setup?key=<SETUP_KEY>&info=1` وتحقق من الويب هوك لكلا البوتين |
| لا أرقام في التقرير | يجب أن يكون حساب إنستغرام احترافياً ومتصلاً في Zernio؛ الحسابات الجديدة تحتاج أياماً من البيانات |
| العرض التجريبي لا يبدأ | المنفذ 8787 أو 8790 مشغول؛ أغلق البرنامج الآخر أو راجع `telegram-bot/test/dev.log` |
