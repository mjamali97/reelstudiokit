# ریل استودیو · راهنمای کامل

**زبان‌ها:** [English](en.md) · فارسی · [العربية](ar.md) · [Türkçe](tr.md) · [Deutsch](de.md) · [Français](fr.md) · [Italiano](it.md)

ریل استودیو یه استودیوی تولید محتواست که داخل [Claude Code](https://claude.com/claude-code) کار می‌کنه. به زبون خودت با Claude
حرف می‌زنی؛ پست‌هات رو برنامه‌ریزی می‌کنه، با لحن برندت می‌نویسه، ریل رو با ۱۴ سبک موشن ادیت می‌کنه، کروسل و استوری و کاور
هایلایت رو با رنگ و فونت برندت می‌سازه، بعد از ✅ خودت از طریق Zernio منتشر می‌کنه و هر صبح آمار رو توی تلگرام می‌فرسته.
برای هر نوع پیجی کار می‌کنه: قنادی، رستوران، آتلیه، سالن زیبایی، کلینیک، فروشگاه آنلاین، متخصص، پیج شخصی، یا آژانسی که چند مشتری داره.

---

## ۱ · اول امتحانش کن (۵ دقیقه، بدون هیچ اکانتی)

<div dir="ltr">

```bash
git clone https://github.com/mjamali97/reelstudiokit.git my-studio
cd my-studio
bash tools/install.sh
bash telegram-bot/demo/demo.sh fa
```

</div>

یه صفحه باز می‌شه با سه ستون: **بات استودیو**، **بات انتشار** و **کانالت**. روی 📝 پیش‌نویس‌ها بزن، روی پست ✅ بزن، بعد ✅ نهایی رو
توی ستون بات انتشار بزن و ببین توی کانال میاد. 📊 داشبورد و 💬 صندوق پیام رو باز کن، یه لینک بفرست. هیچی از کامپیوترت بیرون نمی‌ره.
با Ctrl-C تمومش کن.

نمونه‌های تصویری توی `examples/bakery/` هستن (یه قنادی خیالی): ۱۰ قالب کروسل، ۱۱ قالب استوری، کاور هایلایت.
`fonts/gallery.html` ۵۱ فونت رو نشون می‌ده. توی Claude Code دستور `/demo` همه‌ش رو قدم‌به‌قدم نشونت می‌ده.

## ۲ · چی لازم داری

| | |
|---|---|
| کامپیوتر | مک، لینوکس، یا ویندوز با WSL2 |
| نرم‌افزار | git، Node نسخه‌ی ۲۰ به بالا، Python نسخه‌ی ۳.۱۱ به بالا، ffmpeg، گوگل کروم، uv (`bash tools/install.sh` می‌گه چی کمه و چطوری نصبش کنی) |
| Claude Code | اشتراک Claude یا کلید API |
| اکانت‌ها (فقط برای انتشار واقعی) | اینستاگرام حرفه‌ای، [Zernio](https://zernio.com) (انتشار و آمار)، تلگرام، کلید رایگان Gemini، اکانت رایگان Cloudflare، گیت‌هاب |

سطح‌های نصب: `bash tools/install.sh` (پایه: کروسل، استوری، زیرنویس، ابزار برند، بات‌ها) · `video` (موتور ریل، زمان‌بندی کلمه‌ای
WhisperX، لینتر تایپوگرافی فارسی) · `all` (اسکیل‌های HyperFrames و پلاگین ادیتور NextWork) · `check` (فقط گزارش). همه‌ی ابزارها
و لایسنس‌شون: `tools/STACK.md`.

## ۳ · ستاپ چطوری پیش می‌ره

پوشه رو توی ترمینال باز کن، `claude` رو بزن و بنویس **`/setup`**. یه گفت‌وگوئه، نه فرم؛ هر جا خواستی وایسا، دفعه‌ی بعد از همون‌جا
ادامه می‌ده (`profile/SETUP-STATUS.md`). کلاً حدود یه ساعت.

| مرحله | چی می‌شه | تو چی کار می‌کنی |
|---|---|---|
| ۰ خوش‌آمد | زبونت، ستاپ کامل / اول دمو / مشتری آژانس | انتخاب |
| ۱ شناخت | چه کسب‌وکاری، از قبل چی داری | تیک می‌زنی: سایت، اینستاگرام، برندبوک یا لوگو، منو یا لیست قیمت، گوگل‌مپ؛ لینک و فایل می‌دی |
| ۲ خوندن | Claude سایتت (رنگ، فونت، لوگو، قیمت‌ها)، اسکرین‌شات‌های اینستاگرام و فایل‌هات رو می‌خونه و می‌گه **«این‌ها رو فهمیدم»** با پیش‌نمایش برندت روی فریم‌های واقعی | اشتباه‌ها رو درست می‌کنی |
| ۳ پروفایل و لحن | فقط سؤال‌هایی که از مدارکت درنیومد؛ بعد **لحن برند**: میزان رسمی/خودمونی، «تو» یا «شما»، کلمه‌هایی که می‌گی و نمی‌گی، و تست نمونه («کدوم یکی از این سه تا شبیه خودته؟») | جواب، انتخاب، ویرایش |
| ۴ دیزاین سیستم | ظاهر فعلی‌ت وارد می‌شه، یا سه مسیر کنار هم برای انتخاب؛ بعد روی همه‌ی ابزارها اعمال می‌شه | انتخاب یا ترکیب |
| ۵ اولین آدیت | پیجت از روی داده‌ی عمومی: نقاط قوت، ضعف، ۵ اصلاح اول، بایو و کاور هایلایت آماده | بردهای سریع رو اعمال می‌کنی |
| ۶ برنامه و فرمت‌ها | پلی‌بوک کسب‌وکارت، فرمت کپشن / کروسل / استوری / پست خودت، برنامه‌ی دو هفته‌ی اول | انتخاب |
| ۷–۸ اکانت‌ها و بات‌ها | Zernio، کانال و دو بات تلگرام، Cloudflare و گیت‌هاب، دیپلوی در **حالت تست** | کلیک می‌کنی، کلیدها رو خودت توی `.env` یا گیت‌هاب می‌ذاری |
| ۹ خط پایه | آمار واقعی‌ت، بهترین ساعت‌های انتشار، آدیت کامل | می‌خونی |
| ۱۰ لایو | پست‌ها به کانال می‌رسن، Zernio از حالت تست درمیاد | می‌گی «لایو کن» |

هیچ‌وقت رمز یا کلید رو توی چت نمی‌فرستی. Claude صفحه‌ی درست رو باز می‌کنه؛ خودت کلید رو جای خودش می‌نویسی.

## ۴ · برندت، و عوض کردنش بعداً

هر چیزی که استودیو می‌سازه سه تا فایل رو می‌خونه:
- `brand/brand.json`: رنگ‌ها، فونت‌ها، لوگو، اسم، هندل، زبان. فونت‌ها از کتابخونه‌ی آزاد `fonts/` میان یا فونت خودت که لایسنس داره.
- `profile/CREATOR.md`: واقعیت‌ها: چی می‌فروشی، قیمت‌ها (هر کدوم با منبع)، ساعت کاری، نحوه‌ی سفارش، مشتری‌ها، مدرک‌ها، هدف‌ها.
- `profile/VOICE.md`: لحن: شخصیت، میزان رسمی بودن، «تو» یا «شما»، کلمه‌ها، ایموجی، جواب دادن به مشتری، جمله‌های درست و غلط.

هر کدوم رو با **`/brand`** عوض کن («رنگ‌هامون رو گرم‌تر کن»، «ما هیچ‌وقت نمی‌گیم ارزون»، «این لوگوی جدیدمونه»). اول پیش‌نمایش
نشون می‌ده، بعد `node tools/brand/apply.mjs` تغییر رو به سبک‌های ویدیو، رنگ‌ها و لحن بات می‌رسونه.

**عکس، موزیک، آیکون: فقط چیزی که اجازه‌ی استفاده‌ش رو داری** (`/assets`). داخل کیت: حدود ۷۰۰۰ آیکون (Lucide، Tabler، Phosphor،
Heroicons)، تصویرسازی‌های CC0 که با رنگ برندت رنگ می‌شن (Open Doodles، و آدم‌های Open Peeps از هر کلمه‌ای)، ایموجی Noto، ۵۱ فونت آزاد، و
استوری `location` که نقشه‌ش با رنگ‌های برندت از داده‌ی OpenStreetMap کشیده می‌شه. برای هر ریل با فایل منبع‌ها:
`node tools/assets/fetch.mjs openverse|commons|pexels|pixabay|unsplash "<چی>"` برای عکس، ویدیوی b-roll، موزیک و افکت صوتی CC0.
هیچ‌وقت محتوای غیرتجاری یا share-alike، عکس گوگل یا پست پیج دیگه نه؛ عکس استوک «یه کیک»ه، نه «کیک ما».

هر ریل قبل از اینکه ببینی یه QA خودکار رد می‌کنه (`qa.py`: صورت جایی که نباید، فریم یخ‌زده یا خالی) و یه بررسی چشمی روی شیت
سه فریم در ثانیه. هر کروسل و استوری هم به صورت شیت چک می‌شه.

## ۶ · انتشار

هیچی بدون ✅ تو منتشر نمی‌شه. `/publish` رندر تأییدشده رو به صورت **پیش‌نویس** توی Zernio آپلود می‌کنه، کپشن رو با فرمت خودت
می‌نویسه، گیت کامنت‌به‌دایرکت رو تنظیم می‌کنه و یه کارت به بات استودیو می‌فرسته. یه ✅ اینستاگرام (و یوتیوب) رو زمان‌بندی می‌کنه.
پست کانال تلگرام یه ✅ نهایی دوم توی بات انتشار می‌خواد که دقیقاً همون پست رو نشون می‌ده.

## ۷ · بات‌های تلگرام

دو تا بات روی Cloudflare Worker رایگان. منوشون به زبون تو حرف می‌زنه (`LANG` توی `telegram-bot/wrangler.jsonc`: fa برای فارسی).

| دکمه | کارش |
|---|---|
| 🎬 ریل‌ها · 💡 ایده‌ها · 📝 پیش‌نویس‌ها | خط تولیدت؛ هر لینک یا متنی بفرستی ایده می‌شه، بعد بررسی و امتیاز |
| 📅 برنامه | تقویم محتوا: چی زمان‌بندی شده، چی کمه |
| 📸 استوری · 📰 خبر | هر صبح یه ایده‌ی استوری با لحن خودت، خلاصه‌ی خبر حوزه‌ت (اختیاری) |
| 🔎 سرچ | جواب یه سؤال با منبع |
| 📊 داشبورد | صفحه‌ی خصوصی: فالوور، ریچ، امتیاز پیج، مخاطب، بهترین ساعت‌ها، همه‌ی پست‌ها، تقویم، رقبا |
| 💬 صندوق پیام | کامنت و دایرکت جدید با جواب پیشنهادی با لحن و اطلاعات خودت: ✅ بفرست، ✏️ خودم می‌نویسم، ❌ نادیده |
| ⚙️ وضعیت | چی روشنه، چی توی حالت تسته |
| 👥 مشتری‌ها | فقط حالت آژانس |

**پیام‌های خودکار:** گزارش روزانه ساعت ۹ صبح (فالوورهای دیروز، روند ۷ روزه، امتیاز پیج از ۱۰۰ با پنج بخشش)، گزارش ۲۴ ساعت و ۷ روز
بعد از هر پست (بازدید در مقایسه با میانه‌ی خودت، سیو، شیر، کامنت‌های گیت، فالوور)، گزارش هفتگی رقبا و گزارش PDF ماهانه.

## ۸ · آمار و آدیت

`/analytics` آمار رو از Zernio می‌گیره و چیزهایی که جواب داده رو به‌روز می‌کنه: هوک‌ها، امتیاز سبک‌ها، روزهای انتشار.
`/page-audit` کل پیج رو آدیت می‌کنه (پروفایل، گرید، ترکیب محتوا، ماندگاری، تطابق مخاطب با مشتری، زمان‌بندی، تبدیل، رقبا): نقاط قوت،
ضعف‌ها، ۵ اصلاح اول، برنامه‌ی دو هفته. ماهی یه بار کافیه.

## ۹ · حالت آژانس (چند مشتری)

استفاده برای مشتری‌ها لایسنس تجاری لازم داره (`COMMERCIAL-LICENSE.md`)؛ امتحان کردن حالت آژانس رایگانه.

<div dir="ltr">

```bash
node tools/client.mjs init my-first-client
node tools/client.mjs new cafe-shiraz "Cafe Shiraz"
node tools/client.mjs use cafe-shiraz
```

</div>

برای هر مشتری `/setup` رو بزن (گزینه‌ی «ستاپ یه مشتری»). یه اکانت Zernio با یه **پروفایل** برای هر مشتری، یه جفت بات با
`AGENCY: "on"`: از 👥 مشتری‌ها اضافه‌شون کن، هر مشتری با لینک دعوت وصل می‌شه و گزارش خودش رو می‌گیره، و
`node tools/client.mjs sync <slug> --id <n>` لحن و اطلاعات همون مشتری رو به دستیار صندوق پیام می‌ده. جزئیات: `playbook/AGENCY.md`.

## ۱۰ · به‌روزرسانی

بنویس `/update` (یا `bash tools/update.sh`). نسخه‌ی جدید رو می‌گیره، هر چیزی که مال خودته (پروفایل، برند، فرمت‌ها، ریل‌ها، تنظیمات
بات؛ لیستش توی `.gitattributes`) دست‌نخورده می‌مونه، و می‌گه چی جدیده و آیا کاری لازمه.

## ۱۱ · زبان‌ها

- **محتوا:** هر زبونی که Claude می‌نویسه؛ رندرها راست‌به‌چپ (فارسی، عربی) و چپ‌به‌راست رو با فونت و عدد مناسب درست می‌کنن.
- **منوی بات:** `LANG` = `en`، `fa`، `ar`، `tr`، `de`، `fr`، `it`.
- **این راهنما:** به هر هفت زبان، لینکش بالای صفحه.

## ۱۲ · امنیت و حریم خصوصی

- هیچی بدون ✅ تو منتشر نمی‌شه (برای تلگرام دو بار). آپلودها پیش‌نویسن.
- کلیدها توی `.env` (هیچ‌وقت کامیت نمی‌شه) و سکرت‌های گیت‌هاب/Cloudflare هستن. Claude هیچ‌وقت ازت نمی‌خواد کلید رو توی چت بذاری.
- ریپازیتوری تو خصوصیه؛ خود کیت هیچ داده‌ی شخصی‌ای نداره.
- فقط واقعیت‌های منبع‌دار روی صفحه یا توی کپشن میان؛ قیمت، نظر یا عدد ساختگی نه.
- تست‌های بات روی نسخه‌ی جعلی اجرا می‌شن: `bash telegram-bot/test/all.sh`.

## ۱۳ · رفع مشکل

| توی گزارش عددی نیست | اکانت اینستاگرام باید حرفه‌ای و توی Zernio وصل باشه؛ اکانت تازه چند روز داده لازم داره |
| دمو بالا نمیاد | پورت ۸۷۸۷ یا ۸۷۹۰ اشغاله؛ برنامه‌ی دیگه رو ببند یا `telegram-bot/test/dev.log` رو ببین |
